# Tennis AI Coach — ユーザーマニュアル

**バージョン:** 1.1.0
**対象読者:** すべてのテニスプレイヤー（スマホ操作が初めての方でも分かる丁寧版）

---

## このアプリでできること（30 秒で説明）

スマートフォンをコートサイドに置くだけで、AI（人工知能）が試合をリアルタイム分析して「次のポイントで何をすべきか」を教えてくれるテニス専用コーチアプリです。

**主な機能：**

| 機能 | 用途 |
|------|------|
| 🎾 試合スコア管理 | タップだけで点数管理。デュースルールも 3 種類対応 |
| 📸 試合の録画 | フォーム振り返り用に映像を保存 |
| 🤖 AI リアルタイムアドバイス | チェンジオーバー中に次のゲームの戦術を提案 |
| 🚶 骨格検知 | スイング速度・打点高さ・膝角度を自動測定 |
| 🎯 着弾点マップ | コートのどこに球が落ちたかを可視化 |
| 💡 戦術アドバイザー | カメラなしでも、状況を選ぶだけでプロの戦術を提案 |
| 📱 2 台連携モード | 友達の端末と Bluetooth 接続して両陣を撮影 |
| 📊 試合レポート | ポイント単位で振り返り可能 |

## 1. 準備するもの

### 必須

- **Android スマートフォン**（Android 10 以降、ほとんどの機種が対応）
- **アプリ本体**（APK ファイル、または Google Play から）

### あると便利

- **スマホ用三脚** または **コートフェンス用クリップ**（100 円ショップで買えます）
  → 手で持ち続けるのは大変なので必須レベルです
- **モバイルバッテリー**（録画＋AI 解析でバッテリー消費が早いため）
- **Wear OS スマートウォッチ**（連携機能あり、なくても OK）
- **2 台目のスマホ**（マルチカメラモードを使う場合のみ）

## 2. インストール手順

### 方法 A：APK ファイルから（友達経由）

1. 友達から送られた **`app-debug.apk`** などのファイルをスマホでダウンロード
2. ダウンロード通知をタップ、または「ファイル」アプリで APK を探す
3. APK をタップしてインストール開始
4. **「不明なアプリのインストール」を許可**するか聞かれたら、「**設定**」→「**許可**」をオン
5. 戻ってもう一度 APK をタップ → **インストール**
6. 完了後 **開く** をタップ

### 方法 B：Google Play から

将来 Play ストア公開時に追加予定。

## 3. 初回起動と権限の許可

アプリを開くと、**カメラ・位置情報・Bluetooth 等の権限ダイアログ**が順番に出ます。

### 必ず許可してください

| 権限 | 用途 | 許可しないと... |
|------|------|--------------|
| **カメラ** | 試合の撮影と AI 解析 | カメラ機能が使えない（手動スコア管理のみ） |
| **マイク** | 動画録画の音声 | 録画時に音が入らない |
| **位置情報** | Bluetooth 検索（Android 11 以下） | 2 台連携モードが使えない |
| **Bluetooth スキャン / 接続** | 2 台連携モード | 2 台連携モードが使えない |
| **付近のデバイス** | 2 台連携モード（Android 13 以上） | 同上 |

**全部「許可」または「使用中のみ許可」を選ぶのがおすすめです。**

## 4. プロフィールを登録する

ホーム画面に「プロフィールを設定してください」と出ていたら、まず登録します。

### 手順

1. ホーム画面の **「プロフィールを設定してください」** カードをタップ
   または上部の **👤 アイコン**をタップ
2. 以下を入力：
   - **名前**：呼び名（あだ名でも OK）
   - **レベル**：自分のテニスレベル（5 段階）
     - 初級：始めて間もない
     - 中級：ラリーが続けられる
     - 中上級：試合経験豊富
     - 上級：県大会レベル
     - 競技：全国・国際レベル
   - **性別**：男性 / 女性 / その他
   - **利き手**：右利き / 左利き
3. **保存** をタップ

> 💡 これで AI があなたのレベルに合わせたアドバイスを出せるようになります。後から変更可能です。

## 6. 試合を始める（最重要）

ホーム画面で **「シングルス」** または **「ダブルス」** をタップすると、試合の流れが始まります。

### ステップ ① カメラを設置

最初に **カメラ設置画面** が出ます。

**画面の構成：**

```
┌─────────────────────────────┐
│ ← ① カメラ設置               │ ← 上部
├─────────────────────────────┤
│                             │
│                             │
│   📷 カメラのライブ映像       │ ← プレビュー
│                             │
│                             │
├─────────────────────────────┤
│ ズーム ━━━●━━━━━ 1.5x        │ ← ズームスライダー
│ 広角 1.0x         望遠 5.0x   │
├─────────────────────────────┤
│ 📷 撮影のコツ                 │ ← ヒント
│ ・コートサイドのフェンスに...  │
├─────────────────────────────┤
│ [カメラなしで進む] [設置完了]  │ ← ボタン
└─────────────────────────────┘
```

**操作手順：**

1. スマホを **コートサイド**（フェンス・ネットの脇など）に三脚で固定
2. プレビュー画面で **コート全体が映っているか確認**
3. 必要に応じて **ズームスライダー** で調整
   - **広角 (1.0x)**：近距離からコート全体を映したい時
   - **望遠 (5.0x)**：遠くから細かく撮影したい時
4. **横向き** で撮影したい場合はスマホを横にすればプレビューも横になります
5. 準備 OK なら **「設置完了」** をタップ

> 💡 **設置のコツ**
> - フェンスの上端あたりに横置きで固定するとコート全体が綺麗に映ります
> - 縦向きの場合はベースライン後方の高い位置がおすすめ
> - 100 円ショップの **「自撮り棒型クリップ」** がフェンス固定に便利

> ⚠️ カメラを使わない場合は **「カメラなしで進む」** をタップ。手動スコア管理＋戦術アドバイザーは使えます。

---

### ステップ ② プレイヤー情報を登録

カメラ設置後、**「試合前セットアップ」** ダイアログが出ます。

#### シングルスの場合

入力する項目は **相手選手 1 人分**：

- **名前**（任意。例：「田中さん」）
- **レベル**（5 段階から選択）
- **利き手**（右 / 左）

#### ダブルスの場合

入力する項目は **3 人分**：

- **相手選手 1**：名前 / レベル / 利き手
- **相手選手 2**：名前 / レベル / 利き手
- **パートナー（味方）**：名前 / レベル / 利き手 ← 緑色の枠

> 💡 **名前は省略可能** です。空欄なら「相手選手」「パートナー」と表示されます。

> 💡 利き手を正確に入力するほど AI のアドバイス精度が上がります。例：「相手のバック側を狙え」のような指示が、利き手から逆算して自動で出ます。

---

### ステップ ③ デュースルールを選ぶ

40-40 になったときのルールを 3 つから選びます。

| ルール | 説明 | おすすめの場面 |
|--------|------|---------------|
| **デュース／アドバンテージ** | 40-40 から 2 ポイント連取で勝ち（伝統ルール） | 公式試合・しっかり競りたい時 |
| **ノーアドバンテージ** | 40-40 になったら次の 1 ポイント取った方が勝ち | 草トーナメント・時短したい時 |
| **セミアドバンテージ** | 1 回目のデュースは AD 方式、2 回目以降の 40-40 は次の 1 点で決着 | バランス型・長引きすぎを防ぎたい時 |

選んだら **「試合開始！」** をタップ。タイマーがスタートし、試合画面に移ります。

## 7. 試合中の画面の使い方

### スコアの入れ方

画面中央のスコアボードで管理します：

```
┌─────────────────────────────────┐
│  🎾 あなた          vs    田中さん  │
│        2                  1       │ ← ゲーム数
│        30                 15      │ ← ポイント
│  [+1ポイント]    [+1ポイント]      │ ← 加点ボタン
└─────────────────────────────────┘
```

**ポイント獲得時の操作：**

- **自分が取った** → 左の緑の **「+1ポイント」** をタップ
- **相手が取った** → 右の赤の **「+1ポイント」** をタップ

**システムが自動でやってくれること：**

- 0 → 15 → 30 → 40 の進行
- 40-40 でのデュース処理（選んだルールに従って）
- ゲーム取得時のセット数加算
- セット獲得判定（6 ゲーム先取・2 ゲーム差）
- サーブ権の自動切替
- ゲームポイント・ブレークポイント・セットポイント等の表示

---

### 上部ボタンの説明

画面の上部バーに並ぶボタン：

| アイコン | 機能 |
|---------|------|
| **←** | 試合を中断してホームに戻る |
| **00:23** | 経過時間（試合開始からの時間） |
| **📊（グレー / オレンジ）** | **詳細スタッツ記録モード**のオン/オフ（初期 OFF）。オン時はポイント獲得後に分類シートが出る |
| **🔴 / ⏹** | **録画開始 / 停止**。緑のときは未録画、赤のときは録画中 |
| **🚶（青）** | **骨格表示のオン / オフ** |
| **📹** | カメラプレビューの表示 / 非表示 |
| **■** | **試合終了**（レポートを生成して保存） |

---

### カメラプレビューの操作

📹 アイコンを押すと、画面上部にプレビューが出ます。

```
┌─────────────────────────┐
│ [REC]                  │ ← 録画中のみ表示
│  📷 ライブ映像           │
│                         │
├─────────────────────────┤
│ 広角 ━━━━●━━━━ 望遠 1.5x  │ ← ズームスライダー
└─────────────────────────┘
```

- **ズームスライダー**：試合中も望遠⇔広角を切り替えられます
- **REC マーク**：録画中は赤い丸＋「REC」表示
- **🚶（骨格）をオン**：プレビュー上に簡易棒人間が重ねて表示され、ポーズ検知の動作確認ができます

## 7-2. 詳細スタッツ記録モード

上部バーの **📊 アイコン** が **詳細スタッツ記録モード**のオン/オフ切替です（**初期状態は OFF＝グレー**）。オンにするとオレンジ色になります。

### 詳細スタッツモードとは

各ポイントを獲得したあと、**ポイント分類シート**が下からせり上がってきて、「どんなポイントだったか」を 1 タップで記録できます。

これにより試合終了後に以下が見られます：

- サービスエース数
- ダブルフォルト数
- 1st サーブ確率 / 1st サーブ獲得率
- 2nd サーブ獲得率
- ブレークポイントセーブ率 / 獲得率
- ウィナー / アンフォースドエラー / フォーストエラー
- フォア vs バック ウィナー比
- 平均ラリー長 / 平均球速
- ネットでのポイント勝率

### ポイント分類シートの使い方

ポイントが入った瞬間、画面下から以下のシートが現れます：

```
┌────────────────────────────────────┐
│ ✅ 自分のポイント               [×]  │
│ 1G - 0G　30-15　🛡️ ブレークポイント   │
├────────────────────────────────────┤
│ [先に 1st サーブをフォルトしていた...] │ ← サーバー側のみ
├────────────────────────────────────┤
│ ポイントの種類                       │
│ [⚡ サービスエース] [🎯 サービスW]    │
│ [💥 ウィナー]      [🥅 ネット決定打]  │
│ [🔥 相手のFE]      [🎾 通常の勝ち]    │
├────────────────────────────────────┤
│ ストローク種別（任意）                │
│ [フォア][バック][ボレー][スマッシュ]   │
├────────────────────────────────────┤
│ ラリー数: 5 球      [−] [+]          │
└────────────────────────────────────┘
```

**手順：**

1. **1st サーブをフォルトしていた場合** は、シート上部のボタンを先にタップ → このポイントは 2nd サーブ扱いに
2. **ポイントの種類** をタップ（決定後すぐシートが閉じる）
3. ストローク種別とラリー数は **省略可能**（精度向上に貢献）

### ポイントカテゴリの意味

| カテゴリ | 意味 |
|---------|------|
| ⚡ **サービスエース** | 相手が触れずにサーブで決まった |
| 🎯 **サービスウィナー** | サーブとリターン処理だけで決定打になった |
| ✗ **ダブルフォルト** | 2 回連続でサーブを失敗（自分が失点） |
| 💥 **ウィナー** | 相手が触れない決定打（ラリー中） |
| 🥅 **ネットでの決定打** | ネットに詰めて決めた |
| 🔥 **相手のフォーストエラー** | こちらの良い球で相手が崩されてミス |
| ⚠️ **アンフォースドエラー** | プレッシャーがないのに自分でミス |
| 🎾 **通常のラリー勝ち** | 普通のラリーから決まった |

### モードのオン/オフ

- **初期状態は OFF**。「+1ポイント」を押すとそのまま即加点（シンプル動作）
- 上部バーの 📊 アイコンをタップするとオン（オレンジ）になり、分類シートが出るようになる
- もう一度タップで OFF（グレー）に戻る

> 💡 **おすすめ**：詳しいスタッツが欲しい試合では 📊 をオンに。最初の数ゲームだけでも使うと、自分の傾向（ウィナー多め？UE 多め？）が一目で分かります。サクッとスコアだけ付けたいときは OFF のままで OK。

## 8. チェンジオーバー（90 秒休憩）画面

奇数ゲーム終了時（1-0、2-1 など）に **自動でチェンジオーバー画面** に切り替わります。

### 画面構成

```
┌──────────────────────────────────┐
│ チェンジオーバー         残り 67 秒  │
│ 次のゲームの戦術を選んでください       │
│                                  │
│ [次のゲームへ進む（待たずに開始）]    │ ← スキップボタン
├──────────────────────────────────┤
│ このゲームの着弾点（コート図）        │
│ IN: 8  OUT: 2  合計: 10球          │
├──────────────────────────────────┤
│ 次のゲームの戦術を選択（複数可）       │
│                                  │
│ ⚡ サーブ＆ボレー        [攻撃]    │ ← 戦術カード（タップで詳細）
│ ↗️ 深いクロスラリー       [安定]    │
│ 🎯 バックハンド側を集中攻撃           │
│ ☁️ ロブで高さを使う                  │
│ ...                              │
└──────────────────────────────────┘
```

### 操作

1. **戦術カードをタップ** すると詳細が広がります
2. 詳細を読んで **「この戦術を選ぶ」** をタップで決定
3. もうコートに戻りたい場合は **「次のゲームへ進む（待たずに開始）」** をタップで残り時間を待たずにスキップ可能

> 💡 **戦術カードは AI がリアルタイムで作成**。リード中／ビハインド中、ダブルス／シングルス、相手の利き手など、状況に合わせて中身が変わります。

---

## 9. 試合を終了して記録を残す

試合が終わったら：

1. 画面右上の **■（停止アイコン）** をタップ
2. 「試合終了」確認ダイアログが出る
3. **「終了する」** をタップ
4. AI が試合データを分析して **試合レポート** を自動生成
5. レポート画面に切り替わる（後から見直し可能）

**レポートに含まれる情報：**

- 勝敗
- セットスコア
- 試合時間
- AI が生成した「3 行まとめ」
- **詳細スタッツ（プロ中継レベル）** ↓
- **ポイント単位の分析** （誰が取ったか、その時のアドバイス、ポーズデータ）
- 次回の練習メニュー提案

### 詳細スタッツの内訳

詳細スタッツモードで記録した試合は、レポート画面で以下のセクションが見られます：

#### 🎾 サービス
| 項目 | 説明 |
|------|------|
| サービスエース | 相手が触れずに決まったサーブの数 |
| ダブルフォルト | 2 回連続でサーブを失敗した数 |
| 1st サーブ確率 | 1st サーブが入った確率（プロは 60% 以上） |
| 1st サーブ獲得率 | 1st サーブが入った時にポイントを取った確率 |
| 2nd サーブ獲得率 | 2nd サーブから取った確率（55% 以上が理想） |
| ブレークポイントセーブ | 相手のブレークチャンスを凌いだ率 |

#### 🔄 リターン
| 項目 | 説明 |
|------|------|
| 1st リターン獲得率 | 相手の 1st サーブを返してポイントにした率 |
| 2nd リターン獲得率 | 相手の 2nd サーブを叩いてポイントにした率（高いほど攻撃的） |
| ブレーク獲得率 | チャンスでブレークできた率 |

#### 🏓 ストローク
| 項目 | 説明 |
|------|------|
| ウィナー | 相手が触れずに決まった決定打 |
| アンフォースドエラー | プレッシャーなしで自分のミス |
| フォーストエラー | 相手の良い球で崩されたミス |
| ネットでのポイント | ネットに詰めて取ったポイント |
| 総獲得ポイント | 試合全体のポイント数 |

#### 📊 アドバンストスタッツ
| 項目 | 説明 |
|------|------|
| 平均ラリー長 (Shot Tolerance) | ミスせず続けられた平均球数（耐久力） |
| 平均球速 / 最大球速 | 球速の傾向 |
| FH/BH ウィナー | フォアとバック、どちらで決めているか |
| FH/BH エラー | フォアとバック、どちらが弱点か |

#### ⚖️ ウィナー − アンフォースドエラー（攻撃の質）
- W − UE が **正の値**＝攻撃の質が高い（攻めて取れている）
- W − UE が **負の値**＝自滅気味（要修正）
- 自分と相手を並べて比較表示

> 💡 **プロ中継のスタッツとほぼ同じ指標が並びます。** 自分の弱点が「サーブ」「リターン」「ストローク」のどこにあるか客観的に判断できます。

## 11. 戦術アドバイザー（カメラ不要モード）

「今困ってるけどカメラ準備してる時間ない」「過去の試合を振り返って戦術検討したい」場合に使います。

### 開き方

ホーム画面 → **「戦術アドバイザー」** カードをタップ

### 使い方

1. 画面下部の **状況タグ** から、今の状況に合うものを **タップで複数選択**
   - スコア状況（リード／ビハインド／デュース／タイブレーク等）
   - サーブ／リターン
   - 相手のスタイル（フォア強い／バック弱い／左利き等）
   - 自分のコンディション（疲れ／緊張等）
   - 環境（風／太陽／コート種類）
   - 種目（シングルス／ダブルス）
   - 試合時間帯（序盤／中盤／終盤）
2. タップした瞬間、画面上部に **マッチした戦術** がスコア順で表示される
3. 戦術カードをタップして **詳細（プロの参考事例・実行ステップ・使うべき場面・避けるべき場面）** を確認

### 用意されている戦術（30 種類超）

- フェデラー流ワイド→オープンコート
- ナダル流キックサーブ
- ジョコビッチ流ステップインリターン
- ブライアン兄弟の I フォーメーション
- エドバーグのチップ＆チャージ
- サンプラスのキープ哲学
- 風対策・太陽対策・暑熱対策
- 対左利き・対長身・対小柄
- ベースライナー対策・ネットプレーヤー対策
- ...等

> 💡 **タグを多く選ぶほど精度が上がります**。ただし矛盾するタグ（例：「リード中」と「ビハインド」）を同時に選ぶと無効化されるので注意。

## 12. 2 台連携モード（マルチカメラ）

友達の端末ともう 1 台で **コート両陣を同時撮影** して分析できます。

### 必要なもの

- Android スマホ × 2 台（5 m 以内に置ける位置関係）
- 両方とも本アプリインストール済み
- Bluetooth と位置情報がオン

### 接続手順

1. ホーム画面 → **「2 台連携モード」** タップ
2. **ホスト側の端末だけ** が担当を選択：
   - **自陣（自分／パートナー）担当** ← コートのこちら側を撮る
   - **相手陣（相手）担当** ← 相手側を撮る
   - ※ **参加側は接続したときに自動的に反対の陣になります**（手動で選ぶ必要なし）
3. 片方が **「ホストになる」**、もう片方が **「参加する」** をタップ
4. 「参加する」側の画面に **見つかった端末の一覧** が表示される
5. 接続したい端末をタップ
6. 両端末に **同じ 6 桁の PIN** が表示されるので、目視で一致を確認
7. 自動的に接続完了 → **「接続中」** の緑バッジが出る

> 💡 接続後に **← で前の画面に戻っても接続は維持されます**。完全に切断したいときだけ「セッション終了」を押してください。

### 接続後の画面

```
┌────────────────────────────────┐
│ ✅ 接続完了 — 自陣担当            │
├────────────────────────────────┤
│ コートビュー（自陣 12球 / 相手陣 8球）│
│                                │
│   ⬛⬛⬛  ← 相手陣の着弾点（青）   │
│   ━━━  ← ネット                 │
│   ⬛⬛⬛  ← 自陣の着弾点（緑）     │
│                                │
└────────────────────────────────┘
```

両陣の着弾点がリアルタイムで合成表示されます。

> 💡 マルチカメラモードはまだ **実験段階** です。接続が安定しないことがあるため、重要な試合では従来の単独カメラモードを推奨。

## 14. 困ったときは（トラブル対応）

### Q: アプリが「シングルス」をタップした瞬間にクラッシュする

→ **既知のバグでしたが修正済み**。最新版にアップデート（または再インストール）してください。

### Q: カメラのプレビューが真っ黒のまま

→ カメラ権限を許可していない可能性。**設定 → アプリ → Tennis AI Coach → 権限 → カメラ → 許可**

### Q: 録画ボタンが押せない / 反応しない

→ マイク権限が未許可の可能性。同じく権限設定で確認。

### Q: 2 台連携モードで端末が見つからない

→ 以下を順に確認：
- Bluetooth がオンになっているか（両端末）
- 位置情報がオンになっているか（Android 11 以下）
- 5 m 以内の距離にあるか
- 両端末で同じバージョンのアプリを使っているか
- 一旦両方の「2 台連携モード」を閉じて開き直す

### Q: フォームメトリクスがランダムな値ばかり出る

→ 骨格検知モデル `pose_landmarker_full.task` がアプリに同梱されていない場合、ランダム値（デモ）に切り替わります。最新版なら同梱済みです。

### Q: 試合途中でアプリが落ちた、データはどうなる？

→ 試合中のデータはメモリ上のみ。落ちると失われます。重要な試合では **こまめに録画** を推奨。

### Q: スコアを 1 つ間違えて入れた

→ 残念ながら現バージョンでは「戻る」機能はありません。次の予定機能として実装検討中。

### Q: 横向きにすると一部 UI が崩れる

→ 既知。横向きは録画に集中するための実装で、UI レイアウトは縦向き最適化されています。

### Q: バッテリーが急速に減る

→ カメラ＋AI 処理＋画面常時表示で正常です。**モバイルバッテリー** を併用してください。録画時は特に消費が激しいです。

## 16. プライバシー

このアプリは **完全オフライン** で動作します。

- 録画した動画・スコア・分析結果は **すべて端末内のみに保存**
- インターネット送信は行いません（オプションのクラウド AI を将来追加予定だが、その場合も明示的にオプトイン）
- 個人情報の収集は一切なし
- 友達と動画を共有したい場合は、ご自身でファイルを共有してください

> 💡 録画ファイルは `内部ストレージ/Android/data/com.tennis.ai.coach/files/match_videos/` 内に保存されます（Android 10+ では非公開）。
