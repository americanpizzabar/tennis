# Tennis AI Coach — ユーザーマニュアル

**バージョン:** 1.0.0  
**対象読者:** アプリを使用するすべてのテニスプレイヤー

---

## このアプリでできること

Tennis AI Coach は、スマートフォンをコートサイドに置くだけで、AI（人工知能）がリアルタイムであなたの試合を分析し、「次のポイントで何をすべきか」を教えてくれるテニスコーチアプリです。

**こんな場面で役立ちます：**
- チェンジオーバーの90秒間に「次のゲームで何をすればいいか」を確認したい
- 相手の打ち方に何かパターンがあるか知りたい
- 自分のフォームが崩れていないかチェックしたい
- 試合後に「なぜ負けたか」「次は何を練習すればいいか」を振り返りたい

## 1. はじめる前の準備

### 1.1 スマートフォンの準備

アプリを初めて起動すると、以下のアクセス許可を求めるメッセージが表示されます。それぞれ「許可」をタップしてください。

| 求められる許可 | なぜ必要か |
|---|---|
| カメラ | コートを撮影してボールとフォームを分析するため |
| 動画・写真へのアクセス | 過去の試合動画を読み込んで分析するため |
| マイク | 試合の動画録画をする場合に必要 |

> **ポイント：** カメラの許可は必須です。カメラを許可しないと、リアルタイム解析機能が使えません。

### 1.2 スマートフォンの置き方

リアルタイム解析を使う場合は、スマートフォンをコートサイドに置きます。

**おすすめの設置場所：**
- コート横のベンチやバッグの上
- コート隅のポールなどに立てかける
- ネット支柱の近く（広角に撮れる位置）

**撮影のポイント：**
- なるべくコート全体が画面に映るよう、少し高い位置に置く
- カメラが直射日光に向かないようにする（逆光は検出精度が下がります）
- ダブルスの陣形チェックを使う場合は、コートを斜め俯瞰で撮れる角度が理想

## 2. 初回設定：プロフィールを登録する

アプリを初めて使う時は、まず自分のプロフィールを登録します。  
プロフィールの情報をもとに、AI があなたのレベルや体格に合ったアドバイスを出します。

### 2.1 プロフィール設定の開き方

ホーム画面の右上にある **人物アイコン（👤）** をタップします。

または、ホーム画面に「プロフィールを設定してください」というカードが表示されている場合は、そのカードをタップしても開けます。

### 2.2 入力する内容

#### 名前（任意）
自分の名前を入力します。省略しても構いません。

#### プレイレベル（必須）
あなたのテニスのレベルを 5 段階から選んでください。

| 選択肢 | こんな人向け |
|---|---|
| **初級** | テニスを始めたばかり。ラリーがまだ続かない |
| **中級** | ラリーができるようになってきた。試合も少し経験がある |
| **中上級** | コートに入ればたいていのボールを打ち返せる。スピンや戦術を意識している |
| **上級** | 市民大会などで上位に入ることができる |
| **競技** | 公式ランキングを持っているなど、本格的に試合に出ている |

> **迷ったら：** 自分を少し低めに設定するとアドバイスが実践的になりやすいです。

#### 性別（必須）
「男性」「女性」「その他」から選んでください。  
体格や一般的なプレースタイルの傾向に合わせたアドバイス生成に使います。

#### 利き手（必須）
「右利き」または「左利き」を選んでください。  
サーブの配球パターンやバックハンド側の推薦コースを正しく計算するために必要です。

### 2.3 保存する

入力が終わったら、画面下部の **「保存する」** ボタンをタップします。  
右上のチェックマーク（✓）をタップしても保存できます。

保存後は自動的にホーム画面に戻ります。

### 2.4 プロフィールを後から変更するには

ホーム画面のプロフィールカードにある **編集アイコン（鉛筆マーク）** をタップするか、右上の人物アイコンをタップします。

## 3. 試合を始める

### 3.1 試合の種類を選ぶ

ホーム画面には「シングルス」と「ダブルス」の 2 つのボタンが表示されています。

- **シングルス**（緑のボタン）：1 対 1 の試合
- **ダブルス**（青のボタン）：2 対 2 の試合。パートナーとの陣形チェック機能が追加されます

どちらかをタップすると、すぐに試合画面が開きます。

### 3.2 試合前に確認すること

試合を始める前に、以下を確認してください。

- ✅ プロフィールが正しく設定されている
- ✅ スマートフォンのカメラがコートを向いている
- ✅ 画面の明るさを最大にしている（コートサイドは明るいため）
- ✅ 充電が十分（長い試合は 30〜90 分程度バッテリーを消費します）

## 4. 試合画面の使い方

試合画面は、試合中に必要なすべての情報が縦に並んでいます。上から順に以下の情報が表示されます。

```
┌─────────────────────────────────┐
│  シングルス 試合中     00:00  ■  │  ← タイトルバー
├─────────────────────────────────┤
│         スコアボード              │  ← 現在のスコア（最重要）
├─────────────────────────────────┤
│  [チェンジオーバー中のみ表示]     │  ← 残り時間カウントダウン
├─────────────────────────────────┤
│  [相手の癖検知時のみ表示]         │  ← 赤いアラートバナー
├─────────────────────────────────┤
│  フォームメトリクスカード          │  ← スイング速度・打点・膝角度
├─────────────────────────────────┤
│  着弾点マップ                    │  ← ボールがどこに落ちているか
├─────────────────────────────────┤
│  [ダブルスのみ] 陣形チェック      │  ← パートナーとの立ち位置
├─────────────────────────────────┤
│  AI アドバイスカード              │  ← 今すぐできる戦術アドバイス
└─────────────────────────────────┘
```

### 4.1 スコアを入力する

テニスのスコアは自動カウントではなく、**自分でタップして入力**します。

| ボタン | 操作 |
|---|---|
| **+1 ポイント**（緑） | あなたがポイントを取った時にタップ |
| **+1 ポイント**（赤） | 相手がポイントを取った時にタップ |

ポイントを入力するたびに、スコアが `0 → 15 → 30 → 40 → ゲーム獲得` と自動で更新されます。

**デュースになった時：**  
両者が 40-40 になると自動的にデュースと判定され、次に取ったプレイヤーに「AD（アドバンテージ）」が表示されます。

**チェンジオーバーになった時：**  
ゲーム合計数が奇数になると、自動的にチェンジオーバー画面が表示されます。  
90 秒のカウントダウンが始まり、その間に AI アドバイスを確認できます。

### 4.2 試合を終了する

試合を終わらせる時は、画面右上の **赤い停止ボタン（■）** をタップします。

「試合を終了してレポートを生成しますか？」という確認メッセージが出るので、「終了する」をタップすると試合後レポート画面に移動します。

## 5. AIアドバイスの読み方

### 5.1 アドバイスカードの見方

画面下部に表示される「AI アドバイスカード」には、以下の情報が含まれています。

```
┌──────────────────────────────────────────┐
│ 🎯 戦術アドバイス              [次のポイントで] │
│                                              │
│ 相手バックハンド側（アドベースライン）への    │
│ スライスで崩す！                             │
│                                              │
│ 🎯 アドベースラインへスライス                 │
│    成功率 72%  速度:普通                      │
│                                              │
│ 確信度 78%                          [更新]   │
└──────────────────────────────────────────┘
```

| 部分 | 意味 |
|---|---|
| **絵文字 + タイトル** | アドバイスの種類（配球 / 弱点攻略 / 陣形 / フォームなど） |
| **緊急度ラベル** | いつ実行すべきか（「今すぐ実行」「次のポイントで」「チェンジオーバーで」） |
| **本文** | 具体的に何をすればよいかの説明 |
| **配球パターン（🎯）** | ターゲットゾーン・ボールの種類・速度・成功率 |
| **確信度** | AI がどれだけ確信を持っているか（高いほど信頼性が高い） |

### 5.2 緊急度の意味

| 緊急度 | 表示色 | 意味 |
|---|---|---|
| **今すぐ実行** | 赤背景 | マッチポイントや打点崩れなど、すぐに対処が必要 |
| **次のポイントで** | 青背景 | 次のポイントから試してほしい戦術 |
| **チェンジオーバーで** | グレー背景 | コートを移動する間に頭に入れておく戦術レベルの話 |

### 5.3 アドバイスを手動で更新する

「更新」ボタン（アドバイスカード右下）をタップすると、その瞬間の状況で新しいアドバイスを生成します。

### 5.4 アドバイスの種類と絵文字

| 絵文字 | 種類 | アドバイスの例 |
|---|---|---|
| 🎯 | 配球 | 「相手バックハンド側へのスライスで崩す」 |
| 🔍 | 相手の弱点 | 「相手はバックハンドが苦手。多用して崩そう」 |
| 👥 | 陣形（ダブルス） | 「並行陣に移行して主導権を握る」 |
| 🏃 | フォーム修正 | 「打点が下がっています。足を踏み込んで」 |
| 💪 | メンタル | 「ここは焦らず深いボールでラリーを続ける」 |
| 🔄 | リターン | 「相手の2ndサーブはボディに来やすい。準備して」 |
| ⚡ | ネットプレー | 「アプローチからボレーで決める」 |

### 5.5 ネット接続がない場合のアドバイス

通信環境の悪いコートでも、アプリは **ルールベースモード** で動作します。  
AIモデルを使った高度な分析の代わりに、あなたのレベルや現在のスコア状況に基づいた実践的なアドバイスを表示します。

## 6. 相手の癖アラートとは

試合を続けるうちに、AI が相手選手の「打ち方のクセ」を自動で学習します。  
クセが一定以上確認されると、画面上部に **赤いアラートバナー** が飛び出して通知します。

### 6.1 アラートの見た目

```
┌──────────────────────────────────────────────────┐
│ ⚠️ 相手の癖を検知！                              68% │
│    相手はバックハンドを打つ時、ほぼ必ずスライスになります │
└──────────────────────────────────────────────────┘
```

| 部分 | 意味 |
|---|---|
| 「相手の癖を検知！」 | アラートのタイトル |
| 説明文 | 具体的にどんな癖が見つかったか |
| パーセント（右端） | AI の確信度（この数字が高いほど信頼性が高い） |

**アラートは 3 秒後に自動で消えます。** 見逃した場合も、AI アドバイスカードに同じ内容が反映されます。

### 6.2 検知できる癖の種類

| 癖の内容 | どういう意味か | 活用法 |
|---|---|---|
| バックハンドがほぼ必ずスライス | バックハンドにくると必ずスライスを打ってくる | バックハンド側にボールを集めると、低い球が返ってくるので前に詰めやすい |
| 2nd サーブがボディに集まる | ダブルフォルト避けのためボディを狙ってくる | 少し体を開いてフォアで叩く準備をしておく |
| フォアハンドがクロス多用 | フォアを打つといつもクロス方向に来る | 逆のコーナー（ダウンザライン方向）を空けて待つ |
| トスが左に寄るとワイドへ | サーブのトスで行き先がわかる | トスをよく見てポジションを変える |

### 6.3 何回見たら癖と判断されるか

AI は最低 **5 回以上**の観察データが必要です。試合序盤はまだ癖を判断できません。  
試合が進むにつれて精度が上がります。

## 7. フォームチェック機能

スマートフォンのカメラを通じて、あなたのスイングフォームをリアルタイムで分析します。

### 7.1 フォームメトリクスカードの見方

```
┌─────────────────────────────────────────────┐
│  スイング速度      打点高さ          膝の角度  │
│  87 km/h          112 cm           145°     │
│                                              │
│ ⚠ 打点が下がっています。足を一歩踏み込んで！  │
└─────────────────────────────────────────────┘
```

| 指標 | 説明 | 注意が必要な状態 |
|---|---|---|
| **スイング速度** | ラケットを振る速さ（km/h） | 表示のみ（警告なし） |
| **打点高さ** | ボールを打つ時の手の高さ（cm） | **80cm を下回ると黄色**、**75cm を下回ると警告＋AI が自動でアドバイス生成** |
| **膝の角度** | 打つ時に膝がどれだけ曲がっているか | **170° 以上（ほぼ伸びている）で警告** |

### 7.2 打点が低いと言われた時

「打点が下がっています。足を一歩踏み込んで！」というメッセージが出たら、以下を意識してください。

1. **疲れてくると打点が落ちがち**です。意識して早めに足を動かす。
2. **ひざを軽く曲げた状態**でボールを待つ。
3. ボールをギリギリまで待つのではなく、**早めに準備を始める**。

### 7.3 カメラが映っていない時

コートサイドにスマートフォンを置いていて人物が映っていない場合は、フォームメトリクスは表示されません（または demo データが表示されます）。

フォームチェックを活用したい場合は、**コートの端からあなたが見えるよう**スマートフォンを設置してください。

## 8. 着弾点マップの見方

「着弾点マップ」は、試合中にボールがコートのどこに落ちているかを小さなコート図で示します。

### 8.1 マップの見方

```
┌─────────────────────────────────┐
│        着弾点マップ               │
│  ───────── ネット ─────────      │
│                                  │
│        ●         ●●             │ ← 緑の点 = インコート
│    ●●●          ●              │
│  ──────── サービスライン ────     │
│    ●       ●●     ●            │
│  ─────────────────────────      │
└─────────────────────────────────┘
```

| 色 | 意味 |
|---|---|
| **緑の点** | インコートに入った |
| **黄色の点** | ネットに引っかかった |
| **赤の点** | アウトになった |
| **薄い点** | 古い着弾（直近 50 点を表示。古いほど薄くなる） |
| **濃い点** | 最近の着弾 |

### 8.2 マップの活用法

- **緑の点がベースライン付近に集まっている** → 深いボールが打てている
- **緑の点がサービスボックス付近に集まっている** → ボールが浅い。相手に攻め込まれやすい
- **赤い点がたくさんある** → アウトが多い。スピードを少し落として確率を重視する
- **点が左右のどちらかに偏っている** → 相手のバックハンド側 or フォアハンド側に集まっている。意図的かどうか確認する

## 9. ダブルス専用機能：陣形チェッカー

ダブルスで試合を始めた場合、「陣形チェック」カードが表示されます。

### 9.1 陣形カードの見方

**問題がない場合（緑）：**
```
┌──────────────────────────────────────┐
│ ✓ 陣形チェック                        │
│   雁行陣 — 良い陣形です                │
└──────────────────────────────────────┘
```

**問題がある場合（赤/オレンジ）：**
```
┌──────────────────────────────────────┐
│ ⚠ 陣形チェック                        │
│   センターが空きすぎ！詰めてください   │
└──────────────────────────────────────┘
```

### 9.2 警告の内容と対処法

| 警告メッセージ | 意味 | 対処法 |
|---|---|---|
| **センターが空きすぎ！** | 2人が左右に広がりすぎてコートの真ん中が空いている | 相手からのセンター攻撃に対応できるよう、2 人で中央に寄る |
| **前衛が下がりすぎ** | 前衛役のパートナーがベースライン近くにいる | パートナーはサービスラインより前に出るよう指示する |

### 9.3 陣形の種類

| 陣形名 | 特徴 | 使うタイミング |
|---|---|---|
| **雁行陣**（がんこうじん） | 一人が前（ネット近く）、一人が後ろ（ベースライン近く） | ダブルスの基本陣形 |
| **並行陣**（へいこうじん） | 2人ともネット近くに立つ | 攻撃的にポイントを取りにいく時 |
| **オーストラリアン陣形** | サーバーと前衛が同じサイドに並ぶ | 相手のリターンのコースを限定したい時 |

### 9.4 カメラに 2 人映らない場合

カメラに自分とパートナーの両方が映らないと陣形を判定できません。  
**コートを広角で俯瞰できる位置**にスマートフォンを置いてください。

## 10. 動画から分析する

過去に録画した試合映像や練習動画から、AI がアドバイスを導き出す機能です。

### 10.1 動画分析の開き方

ホーム画面の「動画分析」カードをタップします。

### 10.2 使い方（ステップ順）

#### ステップ 1：動画を選ぶ

画面中央の「タップして動画を選択」カードをタップします。  
端末に保存されている動画ファイルの一覧が表示されます。分析したい動画を選んでください。

> **対応形式：** スマートフォンで録画した動画（MP4 など）に対応しています。

選択後、カードが緑色になり「動画が選択されています」と表示されます。

#### ステップ 2：補足説明を入力する（省略可能）

テキストボックスに、動画の状況を説明する文章を入力できます。

**入力例：**
```
バックハンドのスライスが弱く、相手に攻められてしまう場面が多い。
ラリー中の配球パターンを見てほしい。
```

> 説明を入力しなくても分析できます。その場合は「中級プレイヤーの試合映像」として処理されます。

#### ステップ 3：分析を開始する

「AI で動画を分析する」ボタンをタップします。

AI が 3 つの視点（フォーム・戦術・フットワーク）から順番に分析を行い、進捗バーで進み具合が表示されます。

#### ステップ 4：結果を見る

分析が完了すると、最大 3 件のアドバイスが表示されます。

```
┌──────────────────────────────────────────┐
│ 🏃 フォーム修正                    確信度 75% │
│ スイングフォームの改善                       │
│ 打点が後ろすぎます。もう少し前でとらえる      │
│ ことで、コントロールが向上します。            │
└──────────────────────────────────────────┘
```

### 10.3 分析にかかる時間

| 状態 | 目安時間 |
|---|---|
| Gemini Nano（端末内 AI）が使える場合 | 約 10〜30 秒 |
| ルールベースフォールバックの場合 | 約 3〜5 秒 |

## 11. 試合後レポートを見る

試合を終了すると、AI が自動で試合の分析レポートを作成します。

### 11.1 レポートの開き方

- 試合終了後：自動的に試合後レポート画面に移動します
- 過去のレポート：ホーム画面下部の「最近の試合」リストから見たい試合をタップ

### 11.2 レポートの内容

#### 結果ヘッダー

画面上部に大きく試合結果が表示されます。

```
       勝 利
       6 - 3
  シングルス     45分
```

| 表示色 | 意味 |
|---|---|
| **緑** | 勝利 |
| **赤** | 敗北 |
| **黄色** | 未完了（試合途中で終了した場合） |

#### AI 3行まとめ

試合内容を AI が 3 行で要約します。

```
① 勝利の要因は1stサーブ率63%と積極的な攻めです。
② ウィナー14本・エラー9本。ネットプレーは58%の成功率でした。
③ 次回練習メニュー：バックハンドのコントロールを重点的に。
```

#### スタッツ（成績数値）

| スタッツ | 緑（良い） | 赤（改善が必要） |
|---|---|---|
| 1st サーブ率 | 60% 以上 | 60% 未満 |
| ウィナー | ウィナー > エラー | ウィナー < エラー |
| アンフォースドエラー | エラー < ウィナー | エラー > ウィナー |
| ネットポイント勝率 | 50% 以上 | 50% 未満 |

#### キーモーメント

試合の中で最も重要だったポイントが記録されます。

| マーク | 意味 |
|---|---|
| 👍（緑） | あなたにとってポジティブなプレー |
| 👎（赤） | 改善が必要なプレー |

#### 練習メニュー

今日の試合結果をもとに、次回の練習で取り組むべきメニューが優先順位付きで表示されます。

```
① 1stサーブの精度向上（20分）
   ターゲットを設置して1stサーブの確率を70%以上に引き上げる

② アンフォースドエラー削減（30分）
   クロスラリー100球連続でアウトゼロを目指す
```

## 12. スマートウォッチと連携する（Wear OS）

Wear OS（Android 対応スマートウォッチ）を持っている場合、スマートフォンで分析したアドバイスをリアルタイムでウォッチに送れます。

### 12.1 できること

- スマートフォンで生成したアドバイスをウォッチで確認
- 緊急アラート（相手の癖検知など）をバイブレーションで受け取る
- 現在のスコアをウォッチ画面で確認

### 12.2 ウォッチアプリのインストール方法

1. スマートフォンの Google Play ストアで「Tennis AI Coach」を検索
2. ウォッチアプリをインストール
3. 同じ Google アカウントでペアリング済みのウォッチに自動でインストールされます

> 事前に Google Wear OS アプリでウォッチとスマートフォンをペアリングしておく必要があります。

### 12.3 ウォッチ画面の見方

ウォッチの画面は上から順に表示されます。

```
    4 - 3          ← 現在のスコア
  ─────────────
  ⚠️ 相手の癖！    ← 緊急アラート（出た時のみ）
  バックハンドは
  スライスに注意

  🎯 配球アドバイス
  アドバックハンド
  側へスライスで崩す
```

### 12.4 バイブレーションの種類

| バイブパターン | 意味 |
|---|---|
| 短い振動 × 1 | 通常のアドバイスが届いた |
| 長い振動 × 2 | 緊急度「今すぐ実行」のアドバイスが届いた |
| 短い振動 × 3 | 相手の癖アラートが届いた |

## 13. よくある質問（FAQ）

### Q1. ネット環境がないコートでも使えますか？

**A:** 使えます。AI の一部機能（高度な戦術分析）はネット接続を使いますが、端末内 AI（Gemini Nano）のモデルファイルが設定されていれば完全オフラインで動作します。  
モデルが未設定でも、「ルールベースモード」（あらかじめ組み込まれたルールによるアドバイス）で動作するため、基本機能はすべてオフラインで使えます。

---

### Q2. ボールがうまく検出されません

**A:** 以下を確認してください。

- カメラが直射日光に向いていると検出しにくくなります。逆光を避けてください
- コートの床やネットが黄緑色の場合、誤検出が増えることがあります
- 夜間や薄暗い環境では検出精度が下がります
- テニスボールの色（蛍光黄緑）がカメラの色設定と合わない場合があります

---

### Q3. フォームが映らない場合はどうすればよいですか？

**A:** フォームメトリクス（スイング速度・打点・膝角度）は、カメラにあなたの全身が映っている場合のみ機能します。  
カメラをコートの端から全身が映るよう設置してください。映らない場合はデモ用のサンプル数値が表示されます。

---

### Q4. ダブルスで陣形が表示されません

**A:** 陣形チェックは、カメラに 2 人が映っている場合のみ機能します。  
コートを広角で俯瞰できる位置（コート外からコート全体が見える位置）にスマートフォンを設置してください。

---

### Q5. 試合中にアプリがバックグラウンドになっても解析は続きますか？

**A:** 続きます。試合中はバックグラウンドサービスが動作し、アプリを閉じても解析を継続します。  
通知バーに「試合を解析中…」という通知が表示されている間は解析が動いています。

---

### Q6. 相手の癖がなかなか検知されません

**A:** 癖の検知には最低 5 回以上の同じショットパターンの観察が必要です。  
試合序盤（1〜2 ゲーム目）はまだデータが少ないため検知されにくいです。試合が進むにつれて精度が上がります。

---

### Q7. 試合後レポートを後から見返せますか？

**A:** 見返せます。ホーム画面下部の「最近の試合」リストに直近 5 件が表示されます。  
タップするとレポート画面が開きます。

---

### Q8. プロフィールは複数人分登録できますか？

**A:** 複数のプロフィールを保存できますが、一度に「アクティブ（使用中）」にできるのは 1 件だけです。  
プロフィール設定から新しいプロフィールを保存すると、そのプロフィールがアクティブになります。

---

### Q9. バッテリーの消費が激しいです

**A:** カメラと AI 解析を常時動かしているため、通常より多くバッテリーを消費します。  
長時間の試合では、事前に充電を 80% 以上にしておくことをおすすめします。  
可能であれば、モバイルバッテリーを使いながらプレーする方法もあります。

---

### Q10. スマートウォッチにアドバイスが届きません

**A:** 以下を確認してください。

1. スマートフォンとウォッチが Bluetooth でペアリングされているか
2. ウォッチに Tennis AI Coach のアプリがインストールされているか
3. スマートフォンの Wi-Fi / Bluetooth がオンになっているか
4. ウォッチの電源が入っているか

それでも解決しない場合は、両方の端末を再起動してください。
