# Tennis AI Coach — Android インストール手順書

**対象：** プログラミング未経験の方でも読めるよう、一つひとつ丁寧に解説しています  
**所要時間：** 初回セットアップ 約60〜90分（ダウンロード時間含む）  
**必要なもの：** Windows / Mac パソコン、Android スマートフォン（Android 8.0以上）、USB ケーブル

---

## 全体の流れ

```
STEP 1  パソコンの準備（Java・Android Studioのインストール）
   ↓
STEP 2  ソースコードをパソコンにダウンロードする
   ↓
STEP 3  Android Studio でプロジェクトを開く
   ↓
STEP 4  スマートフォンの開発者設定をオンにする
   ↓
STEP 5  スマートフォンにアプリをインストールする
   ↓
STEP 6  アプリを初めて起動する
   ↓
STEP 7  コートでの使い方
```

---

## STEP 1｜パソコンの準備

### 1-1. Java（JDK 17）をインストールする

Android Studio を使うために必要な「Java」というプログラムをインストールします。

#### Windowsの場合

1. ブラウザで以下のページを開きます  
   `https://adoptium.net/` と検索してください（「Adoptium」というサイトです）

2. 「Latest LTS Release」のボタンをクリックします  
   ※ **JDK 17** と書かれたものを選んでください

3. ダウンロードした `.msi` ファイルをダブルクリックして開きます

4. インストール画面が出たら **「Next」→「Next」→「Install」** の順にクリックします

5. 「Finish」が表示されたら完了です

**インストールの確認方法（Windows）：**
- キーボードの `Windowsキー + R` を押します
- `cmd` と入力して Enter を押します
- 黒い画面（コマンドプロンプト）が開いたら `java -version` と入力して Enter
- `openjdk version "17.x.x"` と表示されれば成功です ✅

#### Macの場合

1. ブラウザで `https://adoptium.net/` を開きます

2. **JDK 17** の `.pkg` ファイルをダウンロードします

3. ダウンロードした `.pkg` ファイルをダブルクリックして、画面の指示に従ってインストールします

**インストールの確認方法（Mac）：**
- `Launchpad` → `ターミナル` を開きます
- `java -version` と入力して Enter
- `openjdk version "17.x.x"` と表示されれば成功です ✅

---

### 1-2. Android Studio をインストールする

Android Studio は、Androidアプリを作るための専用ソフトです（無料）。

1. ブラウザで `https://developer.android.com/studio` を開きます

2. 大きな緑のボタン **「Download Android Studio」** をクリックします

3. 利用規約のページが表示されます。チェックボックスにチェックを入れて **「Download」** をクリックします

4. ダウンロードが完了したらファイルを開きます
   - Windows: `.exe` ファイルをダブルクリック
   - Mac: `.dmg` ファイルをダブルクリック → Android Studio を Applications フォルダにドラッグ

5. インストールウィザードが起動します
   - 「Next」を何回かクリックします
   - インストール先はそのままで OK です
   - 「Install」をクリックして待ちます（5〜10分かかります）

6. インストールが終わったら **「Finish」** をクリックして Android Studio を起動します

7. 初回起動時に **「Setup Wizard」（セットアップウィザード）** が表示されます
   - 「Standard」を選んで「Next」をクリック
   - テーマは好みで選んでください（Darcula = 暗い背景、Light = 明るい背景）
   - 「Finish」をクリックすると、必要なツールが自動でダウンロードされます（10〜20分かかります）

> **⏳ ここは待ち時間が長いです。** 画面の進捗バーがいっぱいになるまで待ちましょう。

8. すべて完了すると **「Welcome to Android Studio」** という画面が表示されます ✅

---

### 1-3. Git をインストールする

ソースコードをダウンロードするための「Git」というツールをインストールします。

#### Windowsの場合

1. `https://git-scm.com/download/win` を開きます
2. 自動でダウンロードが始まります
3. ダウンロードした `.exe` ファイルを開き、すべて「Next」でインストールします

**確認方法：**
- コマンドプロンプトで `git --version` と入力
- `git version 2.x.x` と表示されれば成功 ✅

#### Macの場合

- Mac には最初から Git が入っている場合が多いです
- ターミナルで `git --version` と入力して確認してください
- 表示されない場合は `xcode-select --install` を実行します

## STEP 2｜ソースコードをパソコンにダウンロードする

### 2-1. 保存する場所を決める

ソースコードを保存するフォルダを用意します。  
どこでも構いませんが、わかりやすい場所にしましょう。

**おすすめの場所：**
- Windows: `C:\Users\あなたの名前\Documents\TennisApp`
- Mac: `/Users/あなたの名前/Documents/TennisApp`

### 2-2. コードをダウンロードする

**Windowsの場合：**

1. スタートメニューから「コマンドプロンプト」を開きます

2. 以下のコマンドをそのままコピーして貼り付け、Enter を押します

```
cd %USERPROFILE%\Documents
```

3. 続いて以下を入力して Enter を押します

```
git clone https://github.com/americanpizzabar/tennis.git TennisAICoach
```

4. `Cloning into 'TennisAICoach'...` と表示されてダウンロードが始まります  
   完了すると `TennisAICoach` というフォルダが作られます ✅

**Macの場合：**

1. ターミナルを開きます（Launchpad → ターミナル）

2. 以下を入力して Enter を押します

```
cd ~/Documents
```

3. 続いて以下を入力して Enter を押します

```
git clone https://github.com/americanpizzabar/tennis.git TennisAICoach
```

4. ダウンロード完了を待ちます ✅

## STEP 3｜Android Studio でプロジェクトを開く

### 3-1. プロジェクトを開く

1. Android Studio を起動します

2. **「Welcome to Android Studio」** 画面で **「Open」** をクリックします

3. ファイル選択画面が開くので、先ほどダウンロードした **`TennisAICoach`** フォルダを選んで **「OK」** をクリックします

4. 「Trust and Open Project?」と聞かれたら **「Trust Project」** をクリックします

5. Android Studio がプロジェクトを読み込みます  
   画面下部に進捗バーが表示されます。**完全に止まるまで待ちます**（5〜15分かかります）

> **💡 ポイント：** 画面下に「Gradle sync」「Downloading」などの文字が出ている間は処理中です。終わるまで触らないでください。

### 3-2. ライブラリのダウンロードを待つ

初回は、アプリに必要なライブラリ（部品）を自動でダウンロードします。  
インターネット環境によっては **10〜30分** かかることがあります。

画面右下の通知エリアに進捗が表示されます。「Sync Finished」と出れば完了です ✅

### 3-3. エラーが出た場合の対処法

もし画面下部に赤い文字でエラーが表示された場合：

**よくあるエラーと対処法：**

| エラーメッセージ | 対処法 |
|---|---|
| `SDK location not found` | Android Studio の設定 → SDK Manager で Android SDK をインストール |
| `Gradle sync failed` | 画面下の「Try Again」ボタンをクリック |
| `Could not resolve` | インターネット接続を確認して「Try Again」をクリック |
| `JDK not found` | File → Project Structure → JDK Location で JDK 17 のパスを設定 |

---

### 3-4. （任意）Gemini APIキーを設定する

AIのクラウド機能を使いたい場合のみ設定します。  
**設定しなくてもアプリは動きます（ルールベースモードで動作）。**

1. Google AI Studio（`https://aistudio.google.com/`）でGoogleアカウントでログインします
2. 「Get API Key」→「Create API Key」でキーを取得します
3. Android Studio でプロジェクト内の **`local.properties`** ファイルを開きます  
   （左側のファイルツリーで `Gradle Scripts` → `local.properties`）
4. 以下の1行を追加して保存します

```
GEMINI_API_KEY=ここに取得したAPIキーを貼り付ける
```

---

### 3-5. MediaPipe モデルファイルを追加する（任意・精度向上）

骨格検知（フォームチェック）の精度を上げるためのファイルです。  
**追加しなくてもアプリは動きます（デモ数値が表示されます）。**

1. 以下のURLからモデルファイルをダウンロードします  
   `https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/latest/pose_landmarker_full.task`

2. ダウンロードしたファイルを以下の場所にコピーします  
   `TennisAICoach/app/src/main/assets/`  
   （`assets` フォルダがない場合は新規作成してください）

## STEP 4｜スマートフォンの「開発者モード」をオンにする

パソコンからアプリを直接インストールするために、スマートフォンの隠し設定をオンにします。

### 4-1. 開発者モードを有効にする

1. スマートフォンの **「設定」** アプリを開きます

2. **「端末情報」**（または「デバイス情報」「このデバイスについて」）をタップします

3. **「ビルド番号」** という項目を探します  
   ※ メーカーによって場所が違います。下の表を参照してください

| メーカー | 場所 |
|---|---|
| Google Pixel | 設定 → デバイス情報 → ビルド番号 |
| Samsung | 設定 → デバイス情報 → ソフトウェア情報 → ビルド番号 |
| SHARP / AQUOS | 設定 → デバイス情報 → ビルド番号 |
| Sony Xperia | 設定 → デバイス情報 → ビルド番号 |
| OPPO / OnePlus | 設定 → その他の設定 → デバイス情報 → バージョン情報 → ビルド番号 |

4. **「ビルド番号」を7回連続でタップ**します  
   「あと〇回でデベロッパーになれます」とカウントダウンが表示されます

5. 「開発者になりました」と表示されたら成功です ✅

### 4-2. USB デバッグをオンにする

1. 設定アプリで **「開発者向けオプション」** を開きます  
   ※「システム」や「詳細設定」の中にある場合があります

2. **「USB デバッグ」** のスイッチをオン（青色）にします

3. 「USBデバッグを許可しますか？」と確認が出たら **「OK」** をタップします ✅

---

## STEP 5｜スマートフォンにアプリをインストールする

### 5-1. USB ケーブルで接続する

1. スマートフォンとパソコンを USB ケーブルで接続します

2. スマートフォンに **「このデバイスへのアクセスを許可しますか？」** と表示されたら **「許可」** をタップします

3. **「USB の使用目的を選択」** と表示されたら **「ファイル転送」** を選びます

### 5-2. Android Studio でデバイスを確認する

1. Android Studio の画面上部を見ます

2. 「▶」（実行ボタン）の左側に **デバイスの名前が表示されていれば** 接続成功です  
   例：`Pixel 7 (Android 14)` のような表示

> **表示されない場合：**
> - USBケーブルを抜き差しする
> - スマートフォンの画面ロックを解除する
> - Android Studio の「File」→「Sync Project with Gradle Files」をクリック

### 5-3. アプリをビルド＆インストールする

1. Android Studio 上部の **「▶」（緑の再生ボタン）** をクリックします

2. 画面下部に進捗が表示されます（ビルドに **3〜10分** かかります）

   ```
   Build: Gradle Build Running...
   ↓
   Build: Installing app...
   ↓
   Build: Launch succeeded
   ```

3. スマートフォンに **「Tennis AI Coach」** アプリが自動でインストールされ、起動します ✅

> **エラーが出た場合：**
>
> | エラー | 対処法 |
> |---|---|
> | `INSTALL_FAILED_VERSION_DOWNGRADE` | スマートフォンの古いバージョンを先にアンインストール |
> | `INSTALL_FAILED_INSUFFICIENT_STORAGE` | スマートフォンのストレージを 500MB 以上空ける |
> | `Device offline` | USBケーブルを接続し直し、スマートフォンのロックを解除 |

## STEP 6｜アプリを初めて起動する

アプリが起動したら、最初にいくつかの設定をします。

### 6-1. アクセス許可を許可する

アプリ起動直後に、カメラなどの許可を求めるメッセージが表示されます。  
**すべて「許可」** をタップしてください。

| 許可の内容 | 説明 | 選択 |
|---|---|---|
| カメラへのアクセス | コートを撮影してボールとフォームを分析します | **「許可」** |
| 動画・写真へのアクセス | 過去の試合動画を読み込むために使います | **「許可」** |
| マイクへのアクセス | 動画録画のために使います | **「許可」** |

> **「許可しない」を選んだ場合：**
> カメラを許可しないと、リアルタイム解析機能が使えません。  
> 後から設定を変更する場合は、スマートフォンの **「設定」→「アプリ」→「Tennis AI Coach」→「権限」** から変更できます。

### 6-2. プロフィールを設定する

1. ホーム画面が表示されます。「プロフィールを設定してください」というカードをタップします

2. 以下の情報を入力します

   **名前（任意）**
   - テキストボックスをタップしてキーボードで入力します
   - 省略しても OK です

   **プレイレベル**
   - 自分に一番近いものをタップします
   - タップすると色が変わって選択状態になります

   | 選択肢 | どんな人？ |
   |---|---|
   | 初級 | テニスを始めて1〜2年以内 |
   | 中級 | ラリーが続けられる。クラブで週1〜2回練習 |
   | 中上級 | コースを打ち分けられる。市民大会に出ている |
   | 上級 | 市民大会でベスト8以上に入れる |
   | 競技 | 公式ランキングを持っている |

   **性別**
   - 「男性」「女性」「その他」から選びます

   **利き手**
   - 「右利き」または「左利き」を選びます

3. 画面下の **「保存する」** ボタン（または右上の ✓ マーク）をタップします

4. ホーム画面に戻り、プロフィールカードに情報が表示されれば設定完了です ✅

## STEP 7｜コートでの使い方（試合当日）

### 7-1. スマートフォンをコートに設置する

**おすすめの設置方法：**

```
コート外（ベースラインの後ろ）
　　↑ここにスマートフォンを置く

    ┌─────────────────────────┐
    │         コート          │
    │                         │
    │   ─────── ネット ─────  │
    │                         │
    └─────────────────────────┘
```

- **置き場所：** ベースライン後方のフェンスや椅子の上
- **向き：** カメラがコート全体を映すよう角度を調整
- **高さ：** 腰〜胸くらいの高さが理想（地面に置くと映らないことがあります）
- **角度：** コートを俯瞰できるよう少し前傾みにする

> **100円ショップのスマホスタンドが便利です。** 三脚タイプがおすすめです。

### 7-2. 試合を始める

1. アプリのホーム画面を開きます

2. 試合の種類を選びます
   - **「シングルス」** → 1対1の試合
   - **「ダブルス」** → 2対2の試合

3. 試合画面が開きます。画面に以下が表示されていれば正常です

   ```
   ✅ スコアボード（0-0 と表示）
   ✅ 経過時間（00:00 でカウント中）
   ✅ 着弾点マップ（コート図）
   ✅ AIアドバイスカード（最初のアドバイスが表示）
   ```

### 7-3. 試合中の操作

**ポイントが入ったら：**
- 自分がポイントを取った → 緑の **「+1 ポイント」** ボタンをタップ
- 相手がポイントを取った → 赤の **「+1 ポイント」** ボタンをタップ

**チェンジオーバー（コートチェンジ）の時：**
1. スコアが奇数ゲームになると、自動でカウントダウンが始まります
2. **90秒** の間に画面のアドバイスを確認します
3. カウントダウンが終わると、自動で通常の試合画面に戻ります

**AIアドバイスを新しくしたい時：**
- アドバイスカード右下の **「更新」** をタップします

### 7-4. 試合を終了する

1. 画面右上の **赤い停止ボタン（■）** をタップします
2. 「試合を終了してレポートを生成しますか？」と表示されます
3. **「終了する」** をタップします
4. 試合後レポート画面が表示されます

## よくあるトラブル・Q&A

### ❓ アプリがインストールできない

**原因と対処法：**

1. **「USBデバッグが有効になっていない」**  
   → STEP 4 に戻って USB デバッグをオンにしてください

2. **「デバイスが認識されない」**  
   → USBケーブルを別のものに変えてみてください（充電専用ケーブルはデータ通信できません）

3. **「ストレージが足りない」**  
   → スマートフォンの写真や動画を削除して空き容量を作ってください（最低 500MB）

4. **「Androidのバージョンが古い」**  
   → Android 8.0（Oreo）以上が必要です。設定 → 端末情報 → Androidバージョンで確認してください

---

### ❓ ビルドでエラーが出る（Android Studio）

**よくあるケース：**

**「Gradle sync failed」と出る**
1. インターネットに接続されているか確認する
2. Android Studio の上部メニュー **「File」→「Sync Project with Gradle Files」** をクリック

**「Android SDK not found」と出る**
1. **「File」→「Settings」**（Mac は **「Android Studio」→「Settings」**）を開く
2. **「Appearance & Behavior」→「System Settings」→「Android SDK」** を開く
3. **「SDK Platforms」** タブで Android 14（API 34）または 15（API 35）にチェックを入れる
4. **「Apply」** をクリックしてダウンロードを待つ

---

### ❓ カメラ許可を間違えて「許可しない」にした

**対処法：**

**Android 13以上の場合：**
1. スマートフォンの **「設定」** を開く
2. **「アプリ」→「すべてのアプリ」** から **「Tennis AI Coach」** を探してタップ
3. **「権限」** をタップ
4. **「カメラ」** をタップ
5. **「アプリの使用中のみ許可」** を選ぶ

---

### ❓ ボールが検出されない（着弾点マップに点が出ない）

**確認事項：**
- カメラが逆光（太陽がカメラ方向）になっていないか
- スマートフォンの画面保護フィルムが傷ついていないか
- 薄暗い環境（夕方・曇り）はカメラの明るさ設定（ISO）を上げてみる
- コートサーフェスの色とボールの色が近い場合（赤土コートなど）は精度が下がることがある

---

### ❓ Wear OS スマートウォッチにアドバイスが届かない

**確認手順：**
1. スマートフォンとウォッチが同じ Wi-Fi に接続されているか
2. スマートフォンの Bluetooth がオンか
3. Wear OS アプリがウォッチにインストールされているか
4. 両方の端末を一度再起動してから試す

---
